# NESTA — жилая недвижимость в Амстердаме

Платформа **NESTA** на Payload 3 + Next.js 16: каталог объектов, умный подбор, кабинет клиента, CMS с локализацией RU/EN и Live Preview.

Макет: [Figma](https://www.figma.com/design/p9mgvNBdfGlU7dB3XjaVt2/nesta_promo)

> [English version](./README.en.md)

## Стек

| Слой | Технологии |
| --- | --- |
| Фронтенд | Next.js 16, React 19, Tailwind CSS 4 |
| CMS | Payload 3.89, Lexical, RU/EN UI + локализация контента, Live Preview |
| Данные | Vercel Postgres / Neon (локально Docker) |
| Файлы | Vercel Blob (прод), диск локально |
| Валидация | Zod |
| Уведомления | Sonner |

## Возможности

### Публичный сайт

- **Главная** — hero, поиск, curated-подборка объектов
- **Купить / Аренда** — каталог с фильтрами, картой и сравнением
- **Карточка объекта** — галерея, описание, агент, избранное, запись на просмотр
- **Сравнение** — несколько объектов рядом
- **Районы** — каталог и детальные гиды с аккордеонами и статистикой
- **Умный подбор** — мастер предпочтений (цель, приоритеты, бюджет, спальни) и ранжированные совпадения
- **Агенты** — профиль консультанта, объекты, форма inquire
- **Локализация** RU / EN на всём фронтенде

### Аккаунт клиента

- Регистрация и вход (отдельная коллекция `customers`, без доступа в админку)
- Кабинет (`/dashboard`): обзор, профиль (фото, имя, смена пароля)
- **Избранное** — сердечко на карточках, список `/favorites`
- **Просмотры** — запись на слот, список заявок `/viewings`
- **Сообщения** — только от администратора; прочитано / непрочитано
- **Сохранённые поиски** — сохранение критериев умного подбора (только для авторизованных)

### Админка Payload

- Управление объектами, районами, агентами, страницами, медиа
- Клиенты и их избранное / сохранённые поиски
- Сообщения клиентам
- Заявки на просмотр
- Header / Footer / Site settings
- Live Preview, переключатель языка интерфейса и контента

## Локальный запуск

Нужны Node.js 20+ и Docker:

```bash
cp .env.example .env
docker compose up -d
npm install
npm run dev
```

В другом терминале (после первого старта, когда схема создана):

```bash
npm run seed -- --force
```

- Сайт: http://localhost:3000  
- Админка: http://localhost:3000/admin  

## Скрипты

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Dev-сервер |
| `npm run build` / `npm start` | Прод-сборка и запуск |
| `npm run seed` | Seed (если пусто) |
| `npm run seed -- --force` | Перезаписать seed |
| `npm run generate:types` | Типы Payload |
| `npm run generate:importmap` | Import map админки |
| `npm run lint` | ESLint |

## Маршруты

| Путь | Содержание |
| --- | --- |
| `/` | Главная |
| `/buy`, `/rent` | Каталог покупки / аренды |
| `/properties/[slug]` | Карточка объекта |
| `/compare` | Сравнение объектов |
| `/neighborhoods`, `/neighborhoods/[slug]` | Районы |
| `/matching` | Умный подбор |
| `/agents/[slug]` | Страница агента |
| `/sign-in`, `/register` | Вход и регистрация |
| `/dashboard` | Кабинет (обзор, сообщения, профиль, сохранённые поиски) |
| `/favorites` | Избранное |
| `/viewings`, `/viewings/book` | Просмотры и запись |
| `/admin` | Payload admin |

## Коллекции CMS (основное)

| Коллекция | Назначение |
| --- | --- |
| `properties` | Объекты |
| `neighborhoods` | Районы |
| `agents` | Агенты |
| `customers` | Клиенты сайта (auth) |
| `customer-messages` | Сообщения клиентам (создаёт только админ) |
| `viewing-requests` | Заявки на просмотр |
| `media`, `pages`, `users` | Медиа, страницы, админы |

Globals: `header`, `footer`, `site-settings`.
